        <td>Title of the Project:</td>
        <td>Smart Expense Sharing System</td>
    </tr>
    <tr>
        <td rowspan="3">Objective of the Project</td>
        <td>* This project aims to design and develop a mobile-based Smart Expense Sharing System that enables users to efficiently manage shared expenses within small to medium-sized groups such as friends, university students, or roommates (typically 2–10 members).</td>
    </tr>
    <tr>
        <td>* Shared expenses refer to costs incurred collectively by group members during activities such as dining, trips, accommodation, or group purchases, where one or more individuals pay on behalf of others.</td>
    </tr>
    <tr>
        <td>* The system aims to reduce confusion arising from unclear records of payments, unequal contributions, and manual calculations by providing a simple, accurate, and user-friendly platform to track expenses, calculate balances, and manage settlements.</td>
    </tr>
    <tr>
        <td rowspan="3">Scope of the Project</td>
        <td>* The system will focus on developing a user-friendly mobile application that allows users to create groups, add expenses, and manage shared financial activities within defined groups.</td>
    </tr>
    <tr>
        <td>* The application will support multiple expense splitting methods and provide clear summaries of balances between users. It will also include features such as group management, expense tracking, and settlement recording.</td>
    </tr>
    <tr>
        <td>* Additionally, the system will include enhanced features such as:<br/>o <strong>Intelligent settlement calculation</strong>, which minimizes the number of transactions required to settle all debts within a group<br/>Example:<br/>\* A owes B Rs.500<br/>\* B owes C Rs.500<br/>app says:<br/>“A → C Rs.500” (only 1 payment)</td>
    </tr>

Group admins can add or remove members, while regular members cannot remove others<br/>4. Group admins can assign roles (admin/member) to control group management<br/>5. Users can record expenses with details (amount, payer, participants, description)<br/>6. Only the expense creator or group admin can edit or delete an expense<br/>7. The system maintains an edit history/log to track changes made to expenses<br/>8. The system supports multiple splitting methods:<br/>a. Equal split<br/>b. Unequal split (custom amounts)<br/>c. Percentage-based split<br/>9. The system automatically calculates balances (who owes whom)<br/>10. The system provides optimized settlement suggestions to minimize the number of transactions required<br/>11. Users can view expense history within groups<br/>12. Users can add comments to expenses for communication and clarification<br/>13. Users can record settlements (payments made)<br/>14. The system displays summaries of total owed and receivable amounts<br/>15. The system can send reminders for pending balances</td>
